# رصيد محفظة شروة باي وحركاتها

> **المصدر**: DOC-429 · INT-048 (M40) · الجرد: المجال 8 · آخر مراجعة على الكود: 2026-10-29 (الخطوة 47)

بعد الدخول تعرض محفظة شروة باي أرصدتك بأربع عملات، وكل حركة دخلت المحفظة أو خرجت منها. المصطلحات في [مسرد الأدلة](../../_glossary.md#3-المال-والمحافظ--ثلاث-محافظ-مختلفة).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | عميل شروة باي بعد [الدخول برمز واتساب](sign-in.md) |
| **الصلاحية المطلوبة** | — |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | `/sharwa-pay` على موقع منصة شروة، و«كل الحركات» (`/sharwa-pay/transactions`) |

## المحفظة

![المحفظة: الأرصدة الأربعة وآخر الحركات](../../_assets/sharwa-pay/08-finance/wallet-and-transactions-1.png) <!-- capture: /sharwa-pay after sign-in, mobile 390, mock mode -->

- **اسمك** في الأعلى (أو «محفظتي» إن لم يكن لديك اسم مسجّل).
- **«الأرصدة»**: أربعة أسطر دائماً، واحد لكل عملة، حتى لو كان الرصيد صفراً: «ريال سعودي»، «دولار أمريكي»، «ريال يمني (قديم)»، «ريال يمني (جديد)».
- **«آخر الحركات»** ورابط «كل الحركات».
- **الأزرار**: «شحن» و«سحب»، ورابط «طلباتي (الشحن والسحب)».

> **ملاحظة:** «ريال يمني (قديم)» هو الريال اليمني بسعر صنعاء، و«ريال يمني (جديد)» هو الريال اليمني بسعر عدن. كل رصيد مستقل: لا يُحوَّل رصيد عملة إلى أخرى، ولا يُعرض مجموع واحد للعملات.

## الحركات

![«الحركات» مع فلتري العملة والسبب](../../_assets/sharwa-pay/08-finance/wallet-and-transactions-2.png) <!-- capture: /sharwa-pay/transactions after sign-in, mobile 390, mock mode -->

### الخطوات

1. اضغط «كل الحركات».
2. اختر «العملة» («كل العملات» أو عملة واحدة) و«السبب» («كل الأسباب» أو سبب واحد).
3. تنقّل بين الصفحات بـ «السابق» و«التالي». كل صفحة 20 حركة، الأحدث أولاً.

### ما في كل حركة

| الجزء | معناه |
|---|---|
| السبب | نوع الحركة (الجدول التالي) |
| المبلغ | بإشارة `+` للإيداع و`−` للخصم، مع «إيداع» أو «خصم» تحته |
| المتجر | المتجر الذي تمت فيه الحركة إن كانت من متجر. إن أُغلق المتجر أو أوقفته المنصة يُضاف إلى اسمه «— متجر غير متاح» |
| «طلب #(الرقم)» | رقم الطلب في ذلك المتجر |
| «طلب الشحن #(الرقم)» أو «طلب السحب #(الرقم)» | الطلب الذي نتجت عنه الحركة، ورابط إلى «طلباتي» |
| «الرصيد بعدها (المبلغ)» | رصيد هذه العملة بعد الحركة مباشرة |

| السبب | متى |
|---|---|
| «شحن بمراجعة» | قبلت إدارة شروة طلب شحن رفعتَ إيصاله |
| «شحن تلقائي (بنك)» | وصل تحويلك البنكي وتأكد تلقائياً |
| «شراء» | دفعت طلباً في متجر بشروة باي |
| «استرجاع شراء» | أعاد متجر مبلغ طلب دفعته بشروة باي |
| «سحب» | طلبت سحباً من رصيدك |
| «استرجاع مبلغ سحب مرفوض» | رُفض طلب سحب فعاد مبلغه إليك |
| «رسوم المنصة» | رسوم خصمتها منصة شروة من المحفظة |

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «المحفظة موقوفة — تواصل مع الدعم.» | أوقفت إدارة شروة محفظتك. زرا «شحن» و«سحب» معطّلان | تواصل مع دعم شروة |
| «محفظتك جديدة — اشحنها لتدفع بها في أي متجر على شروة.» | لا محفظة لرقمك بعد | اشحنها من «شحن» |
| «لا حركات بعد.» | لا حركات بعد، أو لا شيء يطابق الفلتر | غيّر الفلتر |
| «لا اتصال — لا نعرض رصيداً قديماً» | لا اتصال بالإنترنت. «تعرض المحفظة أرصدتك من الخادم مباشرة فقط. أعد الاتصال بالإنترنت ثم حدّث الصفحة.» | أعد الاتصال ثم حدّث الصفحة |
| «تعذّر التحميل» | خطأ في الاتصال بالخادم | «إعادة المحاولة» |
| «سجّل الدخول برقم جوالك.» | انتهى دخولك | [ادخل من جديد](sign-in.md) |

## حدود يجب معرفتها

- 20 حركة في الصفحة.
- لا يُعرض رصيد محفوظ مسبقاً أبداً: بلا اتصال لا ترى أي رقم.
- يمكنك إضافة المحفظة إلى شاشة هاتفك الرئيسية من «أضف إلى الشاشة الرئيسية» حين يعرضه المتصفح. في Safari: «في Safari: زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».»
