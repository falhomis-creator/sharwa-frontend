# صفحة المنتج: الخيارات والأسعار والحزم والحجز والمزادات

> **المصدر**: DOC-319 · INT-012 (M10) · الجرد: المجال 5 · آخر مراجعة على الكود: 2026-10-27 (الخطوة 15)

صفحة المنتج تعرض صوره وسعره وخياراته، وما يلزمك قبل إضافته إلى السلة: المقاس أو اللون، أو الكمية، أو موعد الخدمة، أو بيانات التخصيص. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | زائر المتجر (المشتري) |
| **الصلاحية المطلوبة** | لا شيء |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | اضغط أي منتج في المتجر. الرابط بصيغة `/p/<رقم المنتج>` |

## الخطوات

![صفحة منتج له مقاسات وألوان](../../_assets/buyer/05-storefront/product-page-1.png)

1. تصفّح الصور. إن كان للمنتج فيديو اضغط «شاهد فيديو المنتج». اضغط الصورة لتكبيرها.
2. إن كان للمنتج خيارات اختر كل خيار، مثل «المقاس» و«اللون». يتغيّر السعر والصورة والمخزون حسب اختيارك.
3. اختر «الكمية».
4. أكمل ما يطلبه المنتج إن وُجد: الحزمة، أو التخصيص، أو الموعد (الأقسام أدناه).
5. اضغط «أضف إلى السلة» للمتابعة في التسوق، أو «اشترِ الآن» لتنتقل إلى إتمام الطلب بهذا المنتج وحده ([إتمام الطلب](place-order.md)).

تحت الأزرار: «مدة التوصيل» و«الشحن» و«الإرجاع» كما حدّدها المتجر، ورابط «سياسة الاسترجاع». و«مشاركة» تتيح لك إرسال المنتج عبر «واتساب» أو نسخ رابطه.

## ما يظهر في السعر

| ما تراه | المعنى |
|---|---|
| السعر وتحته سعر مشطوب مع «تخفيض» | المنتج مخفّض |
| «من 5 · (عدد) تقييم» | متوسط التقييمات وعددها |
| «بقي (عدد) فقط» | المخزون قليل (حسب حدّ يضعه المتجر، 3 إن لم يحدّده) |
| «نفدت الكمية» | لا مخزون. اضغط «أعلمني عند التوفر» (الفقرة التالية) |
| «متاح للطلب المسبق» | المخزون صفر لكن المتجر يقبل الطلب، ويوفّره لاحقاً |
| «عربون مقدماً: (المبلغ) والباقي عند الاستلام» | تدفع جزءاً عند الطلب، والباقي عند التسليم |
| «وديعة قابلة للاسترداد: (المبلغ)» | مبلغ يُضاف إلى طلبك ويُعاد إليك حسب شروط المتجر (مثل الإيجار أو العبوات) |

كل الأسعار بالعملة التي اخترتها في المتجر ([اختيار العملة](browse-and-search.md#اختيار-العملة)).

**أعلمني عند التوفر:** اضغط الزر، واكتب «رقم واتساب لإشعارك»، ثم «أعلمني». تظهر «سنُنبّهك عبر واتساب عند توفّر المنتج.»

## الكمية والوحدة

- بجانب «الكمية» تظهر وحدة البيع إن حدّدها المتجر (مثل كيلو أو متر).
- قد يضع المتجر حداً أدنى وحداً أعلى للكمية. عند الحد الأعلى يظهر «الحد الأقصى (عدد)» ويتوقف زر الزيادة.
- لا تستطيع طلب أكثر من المخزون المتاح، إلا إن كان المنتج «متاح للطلب المسبق».

### أسعار الكميات

إن ظهر جدول «أسعار الكميات» فسعر الوحدة يقلّ كلما زادت الكمية. العمودان «الكمية من» و«سعر الوحدة». حين تصل كميتك إلى شريحة يظهر «يُطبَّق سعر (عدد)+».

### السعر حسب المقاس (المعادلة)

بعض المنتجات تُسعَّر حسب قيمة تكتبها، مثل الطول أو المساحة. اكتب القيمة في «الكمية (الوحدة)»، فيظهر فوراً «السعر = سعر الوحدة (المبلغ) × المعامل (عدد)»، و«+ إضافة ثابتة» إن وُجدت، ثم «السعر النهائي».

## الحزم

<!-- Screenshot left open — roadmap asks for a bundle product; the fixture id of a bundle in the mock catalog is not known (src/mocks/product-extras was not readable). Add product-page-2 to shots.json once the id is known. -->

الحزمة منتج واحد يضم عدة منتجات. في «محتويات الحزمة»:

1. لكل مكوّن له خيارات اختر الخيار المطلوب («اختر (الخيار) لهذا المكوّن.»).
2. المكوّنات المعلَّمة «اختياري» تستطيع تركها أو إضافتها.
3. يظهر «رسوم التجميع» إن وُجدت، و«إجمالي الحزمة (المكوّنات الأساسية)».

إن نفد أحد المكوّنات الأساسية تظهر بجانبه «نفد»، وتظهر «الحزمة غير متاحة حالياً — ينقصها «(المكوّن)».» ولا يمكن إضافتها.

## التخصيص

إن ظهر قسم «التخصيص» فالمتجر يطلب منك بيانات للمنتج، مثل اسم يُطبع أو صورة.

- الحقول المطلوبة لا تُترك فارغة («هذا الحقل مطلوب.»).
- القوائم: اضغط «اختر» ثم القيمة.
- الملفات المرفوعة حتى 5MB.
- بعض الخيارات تضيف مبلغاً على كل قطعة، يظهر بجانبها «+ (المبلغ)».

## الخدمات بالحجز

<!-- Screenshot left open — roadmap asks for a bookable service; fixture id unknown. Add product-page-3 to shots.json once the id is known. -->

إن كان المنتج خدمة بموعد (مثل جلسة أو حجز طاولة):

1. في «اختر موعداً (المدة (عدد) دقيقة)» اختر اليوم ثم الوقت. «الأوقات بتوقيت المتجر» ثم اسم منطقته الزمنية.
2. إن لم يكن في اليوم موعد تظهر «لا مواعيد متاحة في هذا اليوم.» واضغط «أقرب يوم متاح».
3. حين تختار وقتاً **يُحتجز لك 15 دقيقة**: «محتجز لك حتى (الوقت) · يتبقى…».
4. اضغط «أضف إلى السلة» أو «اشترِ الآن» قبل أن تنتهي المهلة، ثم أكمل الطلب.

إن انتهت المهلة يعود الموعد متاحاً لغيرك.

## المزادات

بعض المنتجات تُباع بالمزايدة. في صندوق المزاد ترى: «المزايدة الحالية»، و«ينتهي بعد» (أو «مفتوح حتى إشعار آخر»)، و«خطوة المزايدة»، و«عدد المزايدات».

1. اضغط «زايد بـ (المبلغ)». تظهر «سُجّلت مزايدتك».
2. إن عرض المتجر سعر شراء فوري اضغط «اشترِ الآن بـ (المبلغ)» لتنهي المزاد لصالحك.

«سيُمدَّد المزاد عند أي مزايدة في الثواني الأخيرة.» يعني أن المزايدة قبل النهاية بقليل تطيل وقت المزاد. منتج المزاد يدخل السلة بكمية 1 دائماً.

## المنتجات المقترحة

أسفل الصفحة قد تظهر: «قد يعجبك» (منتجات مشابهة)، و«الأفضل منه» (بديل أعلى)، و«يُكمِله» (ما يُشترى معه).

## التقييمات

1. في «التقييمات» ترى المتوسط وتوزيع النجوم وآخر التقييمات، و«رد المتجر» إن ردّ. «عرض كل التقييمات» يفتحها كلها، واضغط عدد نجوم لتصفيتها.
2. لتضيف تقييماً اضغط «أضف تقييمك»: اختر النجوم، واكتب «تعليقك»، و«الاسم (اختياري)»، ثم «متابعة».
3. في «تأكيد رقمك» («نرسل رمزاً عبر واتساب لنتأكد أن التقييم من عميل حقيقي.») اكتب رقمك ثم الرمز، واضغط «نشر التقييم».
4. تظهر «شكراً، سيظهر تقييمك بعد المراجعة إن لزم.»

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «اختر (الخيار) أولاً.» / «اختر المقاس واللون أولاً.» | لم تختر كل الخيارات | اختر الخيار الناقص. |
| «اختر موعداً قبل الإضافة إلى السلة.» / «اختر موعداً أولاً لهذه الخدمة.» | خدمة بلا موعد | اختر يوماً ووقتاً. |
| «انتهت مهلة الاحتجاز — اختر موعداً من جديد.» | مرّت 15 دقيقة | اختر الموعد مرة أخرى. |
| «لم يعد هذا الموعد متاحاً.» | حجزه غيرك | اختر وقتاً آخر. |
| «احتجزت مواعيد كثيرة في الوقت نفسه — أكمل الطلب أو أزل بعضها من السلة أولاً.» | لديك 10 مواعيد محتجزة | أكمل طلبك أو أزل مواعيد من السلة. |
| «تعذّر احتجاز الموعد.» | انقطع الاتصال | أعد المحاولة. |
| «أدخل قيمة أكبر من صفر.» | قيمة المعادلة صفر أو فارغة | اكتب قيمة صحيحة. |
| «الملف أكبر من 5MB.» | ملف التخصيص كبير | صغّر الملف. |
| «هذا المنتج غير متاح.» | أُخفي المنتج أو نفد | اختر منتجاً آخر. |
| «المزاد لم يبدأ.» / «انتهى المزاد» / «انتهى المزاد دون بلوغ السعر الاحتياطي.» | حالة المزاد | انتظر بدايته، أو تصفّح غيره. |
| «تعذّر تحميل المزاد.» | انقطع الاتصال | حدّث الصفحة. |
| «اختر عدد النجوم.» / «اكتب تعليقاً قصيراً.» | التقييم ناقص | أكمل التقييم. |
| «حاول بعد دقيقة.» | طلبت رموزاً كثيرة | انتظر دقيقة. |
| «تعذّر الاشتراك.» | لم يُسجَّل تنبيه التوفّر | تحقّق من الرقم وأعد المحاولة. |
