# المزايدة في مزاد

> **المصدر**: DOC-332 · INT-045 (M37) · الجرد: المجال 3 · آخر مراجعة على الكود: 2026-10-27 (الخطوة 16)

بعض المنتجات تُباع بالمزايدة. تزايد باسمك ورقم جوالك، ومن يقدّم أعلى مبلغ حتى النهاية يتواصل معه المتجر. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | زائر المتجر (المشتري) |
| **الصلاحية المطلوبة** | لا شيء — اسمك ورقم جوالك، بلا رمز تحقق |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | صندوق المزاد في صفحة منتج المزاد، مكان «أضف إلى السلة» |

## صندوق المزاد

<!-- Screenshot left open — auction-bidding-1: the auction fixture id is not known (src/mocks/product-extras not readable). Roadmap asks for it; add it to shots.json when it can be produced in mock mode. -->

| ما تراه | المعنى |
|---|---|
| «المزايدة الحالية» | أعلى مزايدة حتى الآن، أو سعر البداية إن لم يزايد أحد |
| «ينتهي بعد» | الوقت الباقي. «مفتوح حتى إشعار آخر» إن لم يحدّد المتجر نهاية |
| «خطوة المزايدة» | أقل زيادة على المزايدة الحالية |
| «عدد المزايدات» | كم مزايدة قُدّمت |

كل المبالغ بالعملة التي اخترتها في المتجر. يتحدّث الصندوق وحده كل 10 ثوانٍ.

## الخطوات

1. اضغط «زايد بـ (المبلغ)». المبلغ هو المزايدة الحالية مضافاً إليها خطوة المزايدة (أو سعر البداية لأول مزايدة).
2. تُفتح «تأكيد المزايدة»: «اكتب اسمك ورقم جوالك ليتواصل معك المتجر إن فزت بالمزاد.»
3. اكتب «الاسم» و«رقم الجوال».
4. اضغط «زايد بـ (المبلغ)». تظهر «سُجّلت مزايدتك».

إن سبقك أحد بمزايدة أعلى قبل أن تضغط، تُرفض مزايدتك ويظهر المبلغ الأدنى الجديد، ويتحدّث الصندوق. اضغط «زايد بـ» من جديد بالمبلغ الجديد.

## التمديد قرب النهاية

حين يقترب المزاد من نهايته تظهر «سيُمدَّد المزاد عند أي مزايدة في الثواني الأخيرة.» أي مزايدة في هذه الفترة تمدّد النهاية، فيُتاح للآخرين الرد عليها. لذلك لا تنتظر الثانية الأخيرة.

## نهاية المزاد

| الحالة | ما تراه |
|---|---|
| لم يبدأ بعد | «المزاد لم يبدأ.» |
| انتهى | زر «انتهى المزاد» متوقف |
| انتهى دون أن تبلغ المزايدات السعر الذي حدّده المتجر سرّاً | «انتهى المزاد دون بلوغ السعر الاحتياطي.» |

السعر الاحتياطي لا يظهر أبداً؛ يظهر فقط بعد النهاية إن لم يُبلَغ.

**مزايدة بسعر الشراء الفوري أو أعلى تُنهي المزاد فوراً.**

## الحقول

| الحقل | إلزامي؟ | القيود |
|---|---|---|
| «الاسم» | نعم | حرفان على الأقل، وحتى 100 حرف |
| «رقم الجوال» | نعم | رقم جوال يمني أو سعودي، مثل `777123456` |

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «اكتب اسمك.» / «أدخل اسمك.» | الاسم فارغ أو قصير | اكتب اسمك. |
| «أدخل رقم جوال صحيحاً، مثل 777123456.» / «أدخل رقم هاتف صحيحاً.» | الرقم غير صحيح | اكتب رقم جوالك. |
| «الحد الأدنى للعطاء (المبلغ).» | سبقك أحد بمزايدة | زايد من جديد بالمبلغ الجديد. |
| «المزاد لم يبدأ بعد.» | المزاد ما زال مسودة | انتظر بدايته. |
| «انتهى المزاد.» | انتهى الوقت أو بلغ أحدهم سعر الشراء الفوري | — |
| «تعذّر تسجيل المزايدة.» | انقطع الاتصال | أعد المحاولة. |
| «تعذّر تحميل المزاد.» | انقطع الاتصال | حدّث الصفحة. |

## حدود يجب معرفتها

- لا رمز تحقق: اسمك ورقمك يكفيان. اكتب رقمك الصحيح، فعليه يتواصل المتجر إن فزت.
- منتج المزاد يدخل السلة بكمية 1 دائماً.
- لا ترى أسماء المزايدين الآخرين ولا أرقامهم.

## قيود معروفة

> **قيد معروف:** زر «اشترِ الآن بـ (المبلغ)» في صندوق المزاد يفتح صفحة إتمام الطلب لهذا المنتج كأي شراء مباشر؛ لا يسجّل مزايدة ولا يُنهي المزاد. راجع الإجمالي في ملخص الطلب قبل التأكيد.
