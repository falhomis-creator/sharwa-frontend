# صفحة نجاح الطلب وإيصال التحويل والتنبيهات

> **المصدر**: DOC-325 · INT-014 (M12) · INT-016 (M44) · الجرد: المجال 5 · آخر مراجعة على الكود: 2026-10-27 (الخطوة 15)

بعد تأكيد الطلب تنتقل إلى صفحة فيها رقم طلبك وحالته وطريقة الدفع والإجمالي، وما الخطوة التالية. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | زائر المتجر (المشتري) |
| **الصلاحية المطلوبة** | لا شيء — من يملك رابط الصفحة يراها |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | تفتح وحدها بعد «تأكيد الطلب». الرابط بصيغة `/checkout/success/<معرّف الطلب>` |

![صفحة «تم استلام طلبك»](../../_assets/buyer/05-storefront/order-success-1.png)

## ما تعرضه الصفحة

| الجزء | ما فيه |
|---|---|
| العنوان | «تم استلام طلبك»، أو «قيد تنفيذ الدفع» / «نتحقق من الدفع…» إن كانت نتيجة الدفع الإلكتروني لم تصل بعد |
| «رقم الطلب #(الرقم)» | رقم طلبك، مع تاريخ الطلب ووقته. احتفظ به للتواصل مع المتجر |
| «حالة الطلب» | مثل «جديد» أو «بانتظار تأكيد الدفع» أو «يتطلب مراجعة دفع» |
| «طريقة الدفع» | مثل «الدفع عند الاستلام» أو «تحويل بنكي / محفظة محلية» أو «شروة باي» |
| «الإجمالي» | إجمالي الطلب |
| «المطلوب الآن (العربون)» / «عند الاستلام» | يظهران إن كان في طلبك عربون |
| المنتجات | كل منتج وخياره وكميته وسعر القطعة |

## ما يحدث بعد ذلك

الجملة تحت التفاصيل تتغيّر حسب طلبك:

| الحالة | ما تراه |
|---|---|
| الدفع الإلكتروني لم يُحسم | «ننتظر تأكيد بوابة الدفع؛ ستتحدّث هذه الصفحة تلقائياً.» — تتحدّث الصفحة كل ثانيتين حتى تصل النتيجة |
| تحويل وصل إيصاله | «وصلنا إيصال التحويل، وسيؤكد المتجر الدفع قريباً.» |
| تحويل بلا إيصال | نموذج «حوّل المبلغ ثم أرفق الإيصال» (الفقرة التالية) |
| الدفع عند الاستلام | «سيتواصل معك المتجر عبر واتساب لتأكيد موعد التوصيل، والدفع عند الاستلام.» |
| غير ذلك | «سنرسل لك تحديثات الطلب عبر واتساب.» |

ثم الأزرار:

- «تتبّع طلبك» يفتح [صفحة التتبّع](track-order.md).
- «واتساب المتجر» يفتح محادثة مع المتجر فيها «مرحباً، بخصوص طلبي رقم» ثم رقم طلبك.
- «متابعة التسوق» يعيدك إلى المنتجات.

## رفع إيصال التحويل لاحقاً

إن ظهر «حوّل المبلغ ثم أرفق الإيصال»:

1. انسخ رقم الحساب بـ «نسخ» وحوّل المبلغ.
2. اكتب «المبلغ المحوَّل (اختياري)».
3. اختر «صورة الإيصال» (JPEG أو PNG حتى 5MB).
4. اضغط «إرسال الإيصال». تظهر «وصلنا إيصال التحويل، وسيؤكد المتجر الدفع قريباً.»

يراجع المتجر الإيصال ويؤكد الدفع؛ تتغيّر الحالة في [صفحة التتبّع](track-order.md).

## تنبيهات تغيّر الحالة

1. اضغط «نبّهني عند تغيّر حالة طلبي».
2. اسمح للمتصفح بالإشعارات.
3. تظهر «سنُنبّهك عند تغيّر حالة طلبك.» لإيقافها اضغط «إيقاف التنبيهات».

لا يظهر هذا الخيار والدفع الإلكتروني ما زال قيد التنفيذ، ولا إن كان متصفحك لا يدعم الإشعارات أو منعتها له من قبل. إن كنت فعّلت التنبيهات في طلب سابق على المتصفح نفسه يُربط الطلب الجديد بها وحده.

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «لم نجد هذا الطلب» | الرابط ناقص أو خطأ | اضغط «العودة إلى المتجر»، أو افتح الرابط من رسالة واتساب. |
| «هذا الطلب لا يحتاج إيصال تحويل.» | الطلب ليس تحويلاً | — |
| «تم تأكيد دفع هذا الطلب، لا حاجة لإيصال.» | أكّد المتجر الدفع | — |
| «أرفق صورة الإيصال.» | لم تختر صورة | اختر الصورة. |
| «الإيصال: صورة JPEG أو PNG حتى 5MB.» / «صيغة الملف غير مدعومة. يُسمح فقط بصور JPEG أو PNG.» | ملف غير مقبول | التقط صورة JPEG أو PNG أصغر. |
| «أدخل المبلغ بالأرقام (مثال: 250.00).» | المبلغ بصيغة خطأ | اكتبه بالأرقام أو اتركه فارغاً. |
| «تعذّر رفع الإيصال.» | انقطع الاتصال | أعد المحاولة. |

## حدود يجب معرفتها

- الصفحة لا تعرض رقمك كاملاً ولا عنوانك.
- الرابط هو ما يفتح الصفحة: لا تشاركه مع من لا تريد أن يرى طلبك.

## قيود معروفة

> **قيد معروف:** إن أرفقت إيصال التحويل مع الطلب فلا يظهر نموذج إرسال إيصال آخر في هذه الصفحة. إن أرسلت صورة خطأ فتواصل مع المتجر عبر «واتساب المتجر».
