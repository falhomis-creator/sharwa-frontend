# تأكيد الطلب: ما يحدث حين تضغط «تأكيد الطلب»

> **المصدر**: DOC-324 · INT-014 (M12) · الجرد: المجال 5 · آخر مراجعة على الكود: 2026-10-27 (الخطوة 15)

هذه الصفحة تشرح الخطوة الأخيرة في «إتمام الطلب»: ما يفحصه المتجر قبل إنشاء طلبك، ولماذا لا يتكرر طلبك إن ضغطت مرتين أو انقطع الاتصال، وما تفعله إن تغيّرت سلتك. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | زائر المتجر (المشتري) |
| **الصلاحية المطلوبة** | لا شيء |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | زر «تأكيد الطلب» أسفل صفحة «إتمام الطلب» (على الجوال مثبّت أسفل الشاشة مع الإجمالي) |

## قبل أن تبدأ

- أكمل [بياناتك والتوصيل](checkout-delivery.md) و[طريقة الدفع](checkout-payment.md).
- تحت الزر: «يتواصل معك» اسم المتجر «عبر واتساب لتأكيد التوصيل.»

## الخطوات

1. اضغط «تأكيد الطلب». يتحوّل الزر إلى «جارٍ تأكيد الطلب…».
2. إن كانت طريقتك تحتاج رمزاً (الدفع عند الاستلام، شروة باي، «الدفع من محفظتي») تُفتح نافذة الرمز. اكتبه واضغط «تأكيد»؛ يُرسل الطلب وحده بعد التأكيد.
3. إن كان في الحقول نقص يُعرض الخطأ تحت الحقل، وتنتقل الصفحة إليه. صحّحه واضغط «تأكيد الطلب» مرة أخرى.
4. حين يُنشأ الطلب تنتقل إلى [صفحة نجاح الطلب](order-success.md).

## ما يُفحص، وبأي ترتيب

| الترتيب | الفحص | إن فشل |
|---|---|---|
| 1 | هل أُرسل هذا الطلب نفسه من قبل؟ | لا خطأ: تُعرض لك الطلبية الأولى ولا يُنشأ طلب ثانٍ |
| 2 | هل مرّت دقيقة على آخر طلب أرسلته؟ | «لقد أرسلت طلباً قبل قليل. يرجى الانتظار دقيقة قبل إرسال طلب جديد.» |
| 3 | هل تغيّر شيء في السلة (منتج أُخفي أو نقص مخزونه)؟ | تحذير التغيير (الفقرة التالية) |
| 4 | الحقول كلها: الاسم، الرقم، العنوان، الدفع، الإيصال | الأخطاء كلها معاً تحت حقولها |
| 5 | الرموز: نقاط الولاء، ثم محفظة العميل، ثم شروة باي، ثم الدفع عند الاستلام | خطأ الرمز |
| 6 | حجز المخزون والموعد وإنشاء الطلب | رسالة السبب |

**أخطاء الحقول تظهر قبل استخدام أي رمز.** فإن نسيت العنوان مثلاً لا يضيع رمز واتساب الذي أدخلته.

## لا يتكرر طلبك

- لكل سلة معرّف واحد يبقى معها حتى ينجح الطلب. إن ضغطت «تأكيد الطلب» مرتين، أو انقطع الاتصال وأعدت المحاولة، تحصل على **الطلب نفسه**.
- إن انقطع الاتصال تظهر «انقطع الاتصال. أعد المحاولة — لن يتكرر طلبك.» اضغط «تأكيد الطلب» مرة أخرى.
- إن فشل الدفع الإلكتروني بوضوح يُلغى الطلب وتعود الكميات، وتستطيع المحاولة مرة أخرى.

## إن تغيّرت سلتك

إن أخفى المتجر منتجاً أو نفد مخزونه وأنت في صفحة إتمام الطلب:

1. تظهر «تغيّرت سلتك أثناء الإكمال — راجع المنتجات قبل التأكيد.» (أو «تحدّثت سلتك، راجعها قبل التأكيد.»).
2. تحتها «تغيّر:» ثم أسماء المنتجات المتغيّرة.
3. يُحدَّث الملخص والإجمالي. راجعهما، وعدّل السلة إن لزم، ثم اضغط «تأكيد الطلب» من جديد.

لم يُنشأ أي طلب ولم يُخصم أي مبلغ.

## «اشترِ الآن»

- «اشترِ الآن» في صفحة المنتج يفتح إتمام الطلب **لهذا المنتج وحده**. سلتك العادية لا تتغيّر، وتبقى كما هي بعد الطلب.
- لا يمكن تطبيق كود خصم في «اشترِ الآن».
- لخدمة بموعد: يُحتجز الموعد الذي اخترته لك عند فتح «اشترِ الآن». إن حجزه غيرك قبل التأكيد يظهر تحذير التغيير باسم الخدمة.

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «لقد أرسلت طلباً قبل قليل. يرجى الانتظار دقيقة قبل إرسال طلب جديد.» | طلب جديد خلال دقيقة من طلب سابق | انتظر دقيقة. |
| «تغيّرت سلتك أثناء الإكمال — راجع المنتجات قبل التأكيد.» | منتج أُخفي أو نقص مخزونه، أو موعد حُجز | راجع «تغيّر:» وأكّد من جديد. |
| «انقطع الاتصال. أعد المحاولة — لن يتكرر طلبك.» | لم يصل الرد | أعد الضغط. |
| «طلب غير مكتمل، أعد تحميل الصفحة.» | الصفحة قديمة أو ناقصة | حدّث الصفحة. |
| «لا يمكن إتمام طلب بسلة فارغة.» | السلة فارغة (ربما أُكمل الطلب من تبويب آخر) | تحقّق من طلباتك أو أضف منتجاً. |
| «اختر موعداً للخدمة من صفحة المنتج.» | خدمة في «اشترِ الآن» بلا موعد | ارجع واختر موعداً. |
| «رمز التأكيد غير صحيح.» | رمز خاطئ | أعد إدخال الرمز. |
| «يرجى إدخال رمز التحقق المرسل عبر واتساب لتأكيد الطلب عند الاستلام.» | لم يُؤكَّد رقمك للدفع عند الاستلام | اكتب الرمز في النافذة. |
| «أكّد استبدال النقاط برمز واتساب أولاً.» | اخترت النقاط دون رمز | اضغط «استبدال» وأدخل الرمز. |
| رسائل الحقول | انظر [التوصيل](checkout-delivery.md#الرسائل-التي-قد-تظهر-لك) و[الدفع](checkout-payment.md#الرسائل-التي-قد-تظهر-لك) | صحّح الحقل. |

| إعادة إرسال الطلب نفسه | مسموحة دائماً، وتعيد الطلب نفسه |
