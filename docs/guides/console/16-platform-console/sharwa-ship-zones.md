# مناطق شروة شيب

> **المصدر**: DOC-440 · INT-031 (M45)، INT-021، INT-047 · الجرد: المجال 16 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 42)

مناطق التوصيل الرسمية لشروة شيب وأسعارها تُدار من هنا بالكامل؛ التاجر يراها في شاشة «شروة شيب» عنده **للقراءة فقط**. الشاشة للمالك وحده: «مشرف تشغيلي» يرى الجدول والخريطة بأزرار معطَّلة وملاحظة «للقراءة فقط — هذا الإجراء لمالك المنصة.».

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | «مالك المنصة» |
| **الحساب المطلوب** | «مالك المنصة» (`superuser`) فقط |
| **ميزة الباقة** | لا تنطبق |
| **للمالك وحده؟** | نعم |
| **مكانها** | «الكتالوج» ← «مناطق شروة شيب» (`/sharwa-ship/zones`) |

## قراءة الشاشة

خريطة فوق الجدول ترسم كل منطقة ذات حدود دائرة (المركز ونصف القطر) داخل حدود اليمن، والجدول: الكود، الاسم، السعر، «المقسوم الحجمي»، المركز، «نصف القطر (كم)»، الحالة («نشطة»/«غير نشطة») والترتيب. المنطقة **بلا حدود جغرافية** تظهر في عمود المركز بالعبارة «بلا حدود» **ولا تُرسم على الخريطة** — مسموح بها لكنها بلا دائرة. مرور المؤشر على صف يبرز دائرته على الخريطة.

## إضافة منطقة

1. اضغط «منطقة جديدة». تفتح لوحة جانبية وصفها: «السعر لكل شحنة بالعملة المختارة؛ المقسوم الحجمي الافتراضي 5000.»
2. املأ الحقول (الجدول أدناه) واضغط «حفظ».

| الحقل | إلزامي؟ | القيود | ملاحظات |
|---|---|---|---|
| «الكود» | نعم | صيغة `AAA-NN` مثل `SAN-01` — ثلاثة أحرف لاتينية كبيرة وشرطة ورقمان | **يُثبَّت عند الإنشاء ولا يتغيّر أبداً**: البوالص الصادرة تحفظه مرجعاً. الحقل مقفول عند التعديل |
| «الاسم» | نعم | حتى 100 حرف | |
| «السعر» | نعم | رقم حتى خانتين عشريتين | |
| «العملة» | نعم | ريال سعودي / دولار / يمني صنعاء / يمني عدن | |
| «خط العرض» و«خط الطول» و«نصف القطر (كم)» | لا | **الثلاثة معاً أو لا شيء**؛ المدى −90…90 و−180…180 ونصف قطر أكبر من صفر | تخزَّن بـ 7 خانات عشرياً. تركتها فارغة = منطقة بلا حدود (تُسعَّر لكن لا تُرسم) |
| «المقسوم الحجمي» | نعم | بين 1000 و10000 | «الافتراضي 5000» |
| «الترتيب» | لا | رقم ≥ 0 | |
| «نشطة» | لا | مفتاح | المنطقة غير النشطة لا تُسعَّر عليها طلبات جديدة |

رسالة الخطأ إن أرسلت المركز دون نصف القطر (أو العكس): «حدود المنطقة ثلاثية: المركز ونصف القطر معاً أو لا شيء.» وإن خالفت صيغة الكود: «مثل SAN-01.» وإن كررت كوداً قائماً: «الكود مستخدم لمنطقة أخرى.»

## تعديل منطقة

«تعديل» تفتح اللوحة نفسها بلا حقل «الكود» (ثابت). حفظ التعديل يظهر «حُفظت المنطقة <الكود>.» وتسري القيمة الجديدة على الطلبات الجديدة.

## حذف منطقة

«حذف» ثم نافذة توضح: «تختفي «<الاسم>» من شروة شيب لكل المتاجر — لا تُسعَّر طلبات جديدة عليها.» البوالص الصادرة سابقاً لا تتأثر: كل بوليصة تحفظ سعر منطقتها لحظة إصدارها.

## حدود يجب معرفتها

- كود المنطقة مرجع دائم في البوالص — حتى المناطق القديمة بصيغ مخالفة (مثل `sanaa_inner_city`) تحتفظ بكودها؛ الصيغة `AAA-NN` إلزامية **للمناطق الجديدة فقط**.
- تعطيل منطقة («نشطة» مطفأة) بديل الحذف الآمن إن كنت تريد إيقاف التسعير عليها مؤقتاً.
