# استيراد المنتجات من ملف CSV أو Excel

> **المصدر**: DOC-308 · INT-045 (M37، المنتجات — المرحلة B) · الجرد: المجال 3 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 29)

تضيف بالاستيراد منتجات كثيرة مرة واحدة من جدول بيانات. يمرّ الاستيراد بثلاث مراحل: رفع الملف، ثم معاينته ومطابقة أعمدته، ثم التنفيذ. لا يُكتب أي منتج قبل المرحلة الثالثة، وكل المنتجات المستوردة تصل **مسودات**. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | مالك المتجر، ومن يملك صلاحية إدارة الكتالوج |
| **الصلاحية المطلوبة** | «إدارة الكتالوج (التصنيفات والعلامات والوسوم والتشكيلات والشارات)» `catalog.manage` — يملكها افتراضياً «مدير المتجر» و«مدير الفرع» (مالك المتجر يملك كل الصلاحيات). بدونها تظهر: «الاستيراد مقصور على مالك المتجر ومدير المتجر أو الفرع.» |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | القائمة الجانبية ← «المنتجات» ← «استيراد CSV» (`/dashboard/products/import`)، أو من قائمة المنتجات ← «المزيد» ← «استيراد CSV» |

## قبل أن تبدأ

جهّز الملف:

- **الصف الأول عناوين الأعمدة.** كل صف بعده منتج واحد.
- عمودان لا بد منهما: **الاسم** و**السعر**.
- اكتب الأسعار أرقاماً فقط، بخانتين عشريتين على الأكثر (`12.5`، `120`)، دون رمز عملة أو فاصلة آلاف.
- إن أردت تصنيفاً للمنتجات فاكتب اسم التصنيف **كما هو في متجرك حرفاً بحرف**.

عناوين تُطابَق تلقائياً:

| العنوان في ملفك | يُطابَق مع |
|---|---|
| `name` · «الاسم» · «اسم المنتج» | «الاسم» |
| `name_en` | «الاسم بالإنجليزية» |
| `sku` | «SKU» |
| `barcode` · «الباركود» | «الباركود» |
| `price` · «السعر» | «السعر» |
| `old_price` | «السعر القديم» |
| `stock` · «المخزون» | «المخزون» |
| `category` · «التصنيف» | «التصنيف» |
| `description` · «الوصف» | «الوصف» |

## الخطوات

### 1. «رفع الملف»

1. افتح «استيراد المنتجات»: «من ملف CSV أو TSV أو XLSX — تُراجع الصفوف قبل أي كتابة، وتصل المنتجات كمسودات.»
2. اضغط «اختر ملفاً (csv, tsv, txt, xlsx)» واختر ملفك. يظهر «جارٍ قراءة الملف…».

![مرحلة «رفع الملف»](../../_assets/merchant/03-catalog/import-products-1.png) <!-- capture: /dashboard/products/import, desktop 1440, mock mode -->

### 2. «المعاينة والمطابقة»

1. يظهر عدد الصفوف وأول 20 صفاً: «(العدد) صفاً · أول 20 معروضة»، وعدد الصفوف التي فيها أخطاء ولن تُستورد.
2. فوق كل عمود قائمة مطابقة. راجع ما طابقته المنصة تلقائياً، وغيّره إن لزم. اختر «تجاهل العمود» لعمود لا تريده.
3. كل حقل يُطابَق مع عمود واحد فقط؛ الحقل المستخدم يتوقف في قوائم الأعمدة الأخرى.
4. عمود «الحالة» يبيّن لكل صف «سليم» أو سبب رفضه. أخطاء الصفوف بعد العشرين في «أخطاء بقية الصفوف».
5. إن لم تطابق الاسم والسعر يظهر «طابِق عمودَي الاسم والسعر على الأقل.» ويتوقف زر الاستيراد.
6. اضغط «استيراد (العدد) منتجاً». أو «ملف آخر» لتبدأ من جديد.

![مرحلة «المعاينة والمطابقة» مع خطأ في صف](../../_assets/merchant/03-catalog/import-products-2.png) <!-- capture: /dashboard/products/import after uploading a fixture CSV with one bad row, desktop 1440, mock mode -->

> **ملاحظة:** أخطاء المعاينة محسوبة بالمطابقة المقترحة. إن غيّرت المطابقة يُعاد فحص كل صف عند التنفيذ.

### 3. «التنفيذ»

1. يظهر شريط التقدّم: «جارٍ الاستيراد… (المنجز)/(الكل)»، وعدد الصفوف المرفوضة.
2. **أبقِ الصفحة مفتوحة.** المنصة تستورد 200 صف في كل خطوة ما دامت الصفحة تسأل عن التقدّم. إن أغلقتها يتوقف التقدّم.
3. حين ينتهي يظهر «اكتمل الاستيراد»، وتحته كل صف مرفوض: «الصف (الرقم): (السبب)».
4. اضغط «عرض المسودات المستوردة» لتراجع المنتجات وتنشرها.

![مرحلة «التنفيذ» وشريط التقدّم](../../_assets/merchant/03-catalog/import-products-3.png) <!-- capture: /dashboard/products/import during a run, desktop 1440, mock mode -->

## ما يحدث بعد ذلك

- كل صف سليم يصبح **منتجاً مسودة**، لا يظهر في المتجر حتى تنشره ([الإجراءات الجماعية](edit-product-and-variants.md#الإجراءات-الجماعية) ← «نشر»).
- المخزون الفارغ = 0.
- **التصنيف يُطابَق بالاسم حرفياً.** إن لم يوجد تصنيف بالاسم نفسه يُستورد المنتج بلا تصنيف، دون رسالة خطأ. أضف التصنيف بعدها.
- يُسجَّل اسمك منشئاً للمنتجات في «سجل التغييرات».
- الأسماء أطول من 200 حرف تُقصّ، وSKU أطول من 100 حرف، والباركود أطول من 64 حرفاً.
- **المهمة تُنفَّذ مرة واحدة.** لإعادة الاستيراد ارفع الملف من جديد.

## الرسائل التي قد تظهر لك

### عند رفع الملف

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «اختر ملفاً.» | لم تختر ملفاً | اختر الملف. |
| «الصيغ المسموحة: csv, tsv, txt, xlsx» | امتداد غير مقبول (مثل pdf) | احفظ الملف بإحدى الصيغ. |
| «صيغة Excel القديمة (.xls) غير مدعومة — احفظ الملف بصيغة .xlsx أو CSV.» | ملف Excel قديم | احفظه بصيغة xlsx أو CSV. |
| «الامتداد xlsx لكن المحتوى ليس ملف Excel.» | الملف ليس Excel حقاً | صدّره من Excel من جديد. |
| «الملف ليس نصاً (CSV) ولا Excel (xlsx).» | محتوى غير مقروء | احفظه CSV أو xlsx. |
| «الملف فارغ.» | ملف بلا محتوى | تحقّق من الملف. |
| «حجم الملف أكبر من 50MB.» | الملف كبير | قسّمه إلى ملفات أصغر. |
| «الملف لا يحوي صفوف بيانات.» | عناوين فقط بلا صفوف | أضف الصفوف. |
| «الملف أكبر من 20,000 صف — قسّمه إلى ملفات أصغر.» | أكثر من 20,000 صف | قسّمه. |
| «الملف يحوي (العدد) عموداً — الحد 200.» | أعمدة كثيرة | احذف الأعمدة غير اللازمة. |
| «الملف ليس بترميز UTF-8؛ احفظه بترميز UTF-8 ثم أعد الرفع.» | ترميز النص غير مقروء | احفظه من Excel بنوع `CSV UTF-8`. |
| «ملف Excel تالف أو ليس بصيغة xlsx.» | ملف xlsx تالف | افتحه في Excel واحفظه من جديد. |
| «لم يُعثر على ورقة بيانات في ملف Excel.» | الملف بلا ورقة | تأكد من وجود ورقة فيها البيانات. |
| «تعذّر قراءة الملف.» | انقطع الاتصال | أعد المحاولة. |

### لكل صف

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «الاسم فارغ» | خانة الاسم فارغة | اكتب الاسم. |
| «السعر فارغ» | خانة السعر فارغة | اكتب السعر. |
| «سعر غير صالح «(القيمة)»» | السعر ليس رقماً بخانتين على الأكثر | اكتبه أرقاماً فقط. |
| «سعر قديم غير صالح «(القيمة)»» | السعر القديم غير صالح | صحّحه أو اترك الخانة فارغة. |
| «مخزون غير صالح «(القيمة)»» | المخزون ليس رقماً بثلاث خانات على الأكثر | صحّحه. |
| «SKU مستخدم مسبقاً «(SKU)»» | SKU لمنتج قائم | غيّره أو اتركه فارغاً. |
| «تعذّر حفظ المنتج (قيمة مكررة).» | قيمة مكررة أخرى | راجع الصف. |

### عند التنفيذ

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «طابِق عمودَي الاسم والسعر على الأقل.» | الاسم أو السعر غير مطابق | طابقهما. |
| «نُفِّذت هذه المهمة مسبقاً.» | المهمة نُفّذت | ارفع الملف من جديد. |
| «مهمة الاستيراد غير موجودة.» | المهمة لم تعد موجودة | ارفع الملف من جديد. |
| «تعذّر بدء الاستيراد.» | انقطع الاتصال | أعد المحاولة. |

## حدود يجب معرفتها

| الحد | القيمة |
|---|---|
| الصيغ | csv, tsv, txt, xlsx |
| الحجم | حتى 50MB |
| الصفوف | حتى 20,000 صف |
| الأعمدة | حتى 200 عمود |
| الترميز | UTF-8 (مع BOM أو بدونه)، أو Windows-1256 (ملفات Excel العربية القديمة) |
| الفاصل بين الأعمدة | يُكتشف تلقائياً: الفاصلة، أو الفاصلة المنقوطة، أو Tab، أو `|` |
| المعاينة | أول 20 صفاً |
| سرعة التنفيذ | 200 صف في كل خطوة |
| العناوين الفارغة | تصبح «عمود (الرقم)» |

**أرقام الصفوف** في الرسائل كما في جدول البيانات: صف العناوين 1، وأول منتج 2.

## قيود معروفة

> **قيد معروف:** إن كان في الملف صف فارغ، فأرقام الصفوف التي بعده في الرسائل تنقص بمقدار الصفوف الفارغة. احذف الصفوف الفارغة قبل الرفع لتطابق الأرقام ملفك.
