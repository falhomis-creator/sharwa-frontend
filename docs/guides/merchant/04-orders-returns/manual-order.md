# إنشاء طلب يدوي

> **المصدر**: DOC-314 · INT-007 (M06) · الجرد: المجال 4 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 30)

الطلب اليدوي لعميل اتصل بك هاتفياً أو راسلك: تختار المنتجات والتوصيل أو الاستلام، ويُحسب الإجمالي عند الإنشاء من أسعار متجرك. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | مالك المتجر وفريقه |
| **الصلاحية المطلوبة** | «تحديث حالة الطلب» `orders.update_status` — يملكها افتراضياً «مدير المتجر» و«مدير الفرع» و«كاشير» (مالك المتجر يملك كل الصلاحيات). مسودة الجملة تحتاج أيضاً «إنشاء طلبات الجملة (B2B)» `orders.create_b2b` |
| **ميزة الباقة** | — |
| **لمالك المتجر فقط؟** | لا |
| **مكانها** | القائمة الجانبية ← «الطلبات» ← «إنشاء طلب جديد» (`/dashboard/orders/new`)، أو زر «طلب يدوي» في شاشة الطلبات |

## قبل أن تبدأ

- للتوصيل: فعّل طريقة توصيل واحدة على الأقل في إعدادات الشحن. للاستلام: نقطة استلام مفعّلة.
- المنتجات تُضاف من كتالوج متجرك، بأسعارها الحالية.

## الخطوات

عنوان الشاشة «طلب يدوي»: «لعميل اتصل هاتفياً: المنتجات، والتوصيل أو الاستلام. يُحسب الإجمالي عند الإنشاء.»

1. اكتب في «ابحث بالاسم أو SKU» واضغط المنتج لإضافته. اضغطه مرة أخرى لزيادة كميته.
2. لكل منتج له متغيرات اختر «اختر المتغير». المتغير النافد يظهر معه «— نفد».
3. عدّل الكمية بزرّي «زيادة الكمية» و«إنقاص الكمية»، أو احذف السطر بـ«إزالة «(المنتج)»».
4. اكتب «رقم الهاتف» و«الاسم» للعميل.
5. اختر «طريقة الاستلام»:
   - «توصيل»: اختر «طريقة التوصيل» واكتب «العنوان».
   - «استلام من فرع»: اختر «نقطة الاستلام».
6. إن كنت تملك صلاحية الجملة، اختر «النوع»: «طلب هاتفي» أو «مسودة جملة (بانتظار الموافقة)».
7. اضغط «إنشاء الطلب» (أو «إرسال المسودة للموافقة»). يظهر «أُنشئ الطلب #(الرقم)» وتنتقل إلى صفحة الطلب.

## الحقول

| الحقل | إلزامي؟ | القيود | ملاحظات |
|---|---|---|---|
| المنتجات | نعم | منتج واحد على الأقل | خدمات الحجز لا تُطلب من هنا |
| «رقم الهاتف» | نعم | رقم يمني أو سعودي | الرقم الذي يبدأ بـ `05` أو `5` يُعدّ سعودياً، وغيره يمنياً، ويُحوَّل إلى الصيغة الدولية |
| «الاسم» | نعم | حتى 150 حرفاً | |
| «طريقة الاستلام» | نعم | «توصيل» أو «استلام من فرع» | |
| «طريقة التوصيل» | للتوصيل | طريقة مفعّلة | إن لم تختر تُستخدم أول طريقة مفعّلة. رسومها تُضاف إلى الإجمالي |
| «العنوان» | للتوصيل | — | |
| «نقطة الاستلام» | للاستلام | نقطة مفعّلة | |
| «النوع» | لمن يملك `orders.create_b2b` | «طلب هاتفي» · «مسودة جملة (بانتظار الموافقة)» | |

## ما يحدث بعد ذلك

| | طلب هاتفي | مسودة جملة |
|---|---|---|
| الحالة | «جديد»، الدفع «غير مدفوع» | «جديد» بانتظار الموافقة |
| الدفع | الدفع عند الاستلام: الإجمالي كله مستحق عند الاستلام | لا مستحق عند الاستلام |
| حالة التنفيذ | الحالة الافتراضية | بلا حالة حتى الموافقة |
| المخزون | **يُخصم فوراً**، وتُسجَّل حركة بيع «طلب #(الرقم)» | لا يُخصم حتى الموافقة |
| الجدول الزمني | «أُنشئ طلب هاتفي يدوياً.» | «أُنشئت مسودة جملة بانتظار الموافقة.» |

- الأسعار من الكتالوج محوّلة إلى عملة متجرك، لا يُكتب سعر يدوياً.
- الطلب يُنشأ كله أو لا يُنشأ: سطر خاطئ واحد يمنع الإنشاء ولا يُخصم أي مخزون.
- اعتماد مسودة الجملة أو رفضها من «مسودات الجملة» ([البيع بالجملة](../09-b2b/README.md)). المسودة تُرسل من حساب موظف، لا من حساب مالك المتجر.

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «أدخل اسم العميل.» | الاسم فارغ | اكتب الاسم. |
| «150 حرفاً على الأكثر.» | الاسم طويل | اختصره. |
| «أدخل رقم الهاتف.» | الهاتف فارغ | اكتب الرقم. |
| «رقم هاتف غير صحيح.» | ليس رقماً يمنياً أو سعودياً صالحاً | تحقّق من الرقم. |
| «أضف منتجاً واحداً على الأقل.» | لا منتجات | أضف منتجاً. |
| «اختر المتغير.» | منتج بمتغيرات دون اختيار | اختر المتغير. |
| «المتوفر (العدد) فقط.» | الكمية أكبر من المخزون | خفّض الكمية. |
| «كمية غير صحيحة.» | الكمية غير صالحة | صحّحها. |
| «المنتج غير موجود.» / «المتغيّر غير موجود.» | حُذف المنتج أو المتغير | أزله وأضف غيره. |
| «الخدمات القابلة للحجز تُطلب من صفحة الحجوزات.» | أضفت خدمة حجز | احجزها من الحجوزات. |
| «أدخل عنوان التوصيل.» | العنوان فارغ | اكتب العنوان. |
| «طريقة التوصيل غير متاحة.» | الطريقة أُوقفت | اختر غيرها. |
| «اختر نقطة الاستلام.» | لم تختر نقطة | اختر نقطة مفعّلة. |
| «ليست لديك صلاحية إنشاء مسودات الجملة.» | لا تملك `orders.create_b2b` | اختر «طلب هاتفي». |
| «يتطلب إنشاء مسودة الجملة تسجيل دخول موظف.» | أرسلت المسودة من حساب المالك | ادخل بحساب موظف. |
| «لا يوجد فرع متاح — أنشئ فرعاً أولاً.» | لا موقع مفعّل للمسودة | أنشئ موقعاً. |
| «لا يوجد دور «مدير المتجر» لاعتماد المسودة.» | الدور النظامي غير موجود | تواصل مع الدعم. |
| «تعذّر إنشاء الطلب.» | انقطع الاتصال | أعد المحاولة. |

إن لم تملك الصلاحية ترى: «إنشاء الطلبات يدوياً يتطلب صلاحية «تحديث حالة الطلب».»

## حدود يجب معرفتها

- طلب الهاتف يرفض كمية أكبر من المخزون، إلا لمنتج يسمح بالطلب عند نفاد المخزون.
- مسودة الجملة لا تفحص المخزون عند الإنشاء.

## قيود معروفة

> **قيد معروف:** لا يصل العميل أي إشعار (واتساب أو تنبيه) عند إنشاء الطلب اليدوي أو مسودة الجملة. أبلغه بنفسك.
