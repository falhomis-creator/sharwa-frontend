# طابور AWB ولقطات تسعيرة الناقلين

> **المصدر**: DOC-381 · INT-047 (M39) · الجرد: المجال 11 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 34)

شاشتان لبوالص شركات الشحن الخارجية (أرامكس وسمسا): «طابور AWB» يعرض طلبات الإصدار لدى الشركة ونتيجتها، و«لقطات التسعيرة» تقارن سعر كل منطقة بآخر سعر مؤكَّد. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | مالك المتجر؛ من يملك «عرض الطلبات» يقرأ الشاشتين |
| **الصلاحية المطلوبة** | «عرض الطلبات» `orders.view` للقراءة. «إعادة المحاولة» لمالك المتجر وحده |
| **ميزة الباقة** | «شروة شيب» `sharwa_ship` — إن كانت متوقفة: «الميزة غير مفعَّلة لمتجرك» |
| **لمالك المتجر فقط؟** | إعادة المحاولة نعم |
| **مكانها** | «بوليصات شروة شيب» ← «طابور AWB» (`/dashboard/shipping/sharwa-ship/queue`) · «لقطات التسعيرة» (`/dashboard/shipping/sharwa-ship/rate-cards`) |

## طابور AWB

«طلبات إصدار بوليصات الناقلين الخارجيين المعلّقة، بعدد المحاولات وآخر خطأ.»

| العمود | معناه |
|---|---|
| «التجهيز» · «الطلب» | الشحنة وطلبها |
| «الناقل» | أرامكس أو سمسا |
| «الحالة» | «معلّق — سيُعاد المحاولة» · «قيد المعالجة» · «صدرت» · «فشل نهائي» |
| «المحاولات» | عدد المحاولات حتى الآن |
| «آخر خطأ» | نص الخطأ من الناقل، أو «—» |
| «آخر تحديث» | وقت آخر تغيير |

![«طابور إصدار AWB»](../../_assets/merchant/11-shipping/awb-queue-and-rate-cards-1.png) <!-- capture: /dashboard/shipping/sharwa-ship/queue, desktop 1440, mock mode -->

### إعادة المحاولة

1. ابحث عن صف حالته «فشل نهائي». زر «إعادة المحاولة» يظهر لهذه الصفوف فقط.
2. اضغط «إعادة المحاولة». يظهر «أُعيدت المحاولة — العنصر معلّق الآن.»
3. يعود الصف إلى «معلّق — سيُعاد المحاولة»، ويُحاوَل في الخلفية. حدّث الصفحة بعد قليل لترى النتيجة.

- المتجر يعيد محاولة كل الصفوف المعلّقة تلقائياً كل 15 دقيقة.
- إعادة محاولة صف واحد تعيد محاولة كل الصفوف المعلّقة معه.
- قبل إعادة المحاولة تحقّق من [بيانات الناقل](carriers.md)، فكثير من الأخطاء سببها بيانات حساب ناقصة أو خاطئة.

### إشعار فشل الإصدار

حين يفشل إصدار نهائياً يظهر في جرس [الإشعارات](../02-dashboard-shell/notifications.md) لمن يملك «عرض الطلبات»:

- العنوان «فشل إصدار بوليصة للطلب #(الرقم)»؛
- النص هو خطأ الناقل، أو «استنفدت المحاولات لدى الناقل.»؛
- الضغط عليه يفتح «طابور AWB».

يختفي الإشعار وحده حين يخرج الصف من «فشل نهائي» (مثلاً بعد إعادة المحاولة).

## لقطات التسعيرة

«السعر المتوقع لكل منطقة مقابل آخر سعر مؤكَّد؛ الانحراف فوق 10% ينتظر التأكيد قبل الإصدار.»

| العمود | معناه |
|---|---|
| «الناقل» · «المنطقة» | الناقل الخارجي ورمز المنطقة |
| «المتوقع» | السعر المتوقع الآن |
| «آخر مؤكَّد» | آخر سعر أُكِّد، أو «—» إن لم يُؤكَّد سعر قط |
| «الانحراف» | الفرق بالنسبة المئوية، مثل `+20.0%`، أو «—» |
| «الحالة» | «بانتظار تأكيد التسعيرة» أو «مؤكَّدة» |
| «تحديث» | وقت آخر لقطة |

- **«بانتظار تأكيد التسعيرة»** حين يتجاوز الفرق 10% صعوداً أو نزولاً، **وكذلك حين لم يُؤكَّد سعر قط**.
- الشاشة للقراءة؛ لا تأكيد للتسعيرة من لوحة المتجر.

![«لقطات تسعيرة الناقلين»](../../_assets/merchant/11-shipping/awb-queue-and-rate-cards-2.png) <!-- capture: /dashboard/shipping/sharwa-ship/rate-cards, desktop 1440, mock mode -->

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «إعادة المحاولة متاحة للعناصر الفاشلة فقط.» | الصف لم يعد «فشل نهائي» | حدّث الصفحة. |
| «العنصر غير موجود.» | حُذف الصف | حدّث الصفحة. |
| «تعذّرت إعادة المحاولة.» | خطأ في الاتصال | أعد المحاولة. |
| «هذا الإجراء مقصور على مالك المتجر.» | موظف يضغط «إعادة المحاولة» | الإجراء لمالك المتجر. |
| «ليست لديك صلاحية لعرض الشحنات.» | لا تملك «عرض الطلبات» | اطلبها من مالك المتجر. |
| «لا طلبات إصدار معلّقة» · «لا لقطات تسعيرة بعد» | لا صفوف | لا شيء. |

## حدود يجب معرفتها

- الطابور يعرض أحدث 200 صف، الأحدث تحديثاً أولاً.
- اسم المنطقة في لقطات التسعيرة هو رمزها إن حُذفت المنطقة من المنصة.
