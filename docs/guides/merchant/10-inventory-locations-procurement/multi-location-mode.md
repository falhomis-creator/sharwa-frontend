# تشغيل تعدد المواقع وإيقافه

> **المصدر**: DOC-365 · INT-025 · INT-010 (M34) · الجرد: المجال 10، المجال 12 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 33)

«تعدد المواقع» يجعل لكل فرع أو مستودع مخزونه المستقل. حين يكون متوقفاً فلكل منتج رقم واحد للمخزون. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | مالك المتجر فقط |
| **الصلاحية المطلوبة** | لا يوجد مفتاح صلاحية؛ التشغيل والإيقاف لمالك المتجر. يرى الموظف: «التفعيل مقصور على مالك المتجر» أو «تحتاج صلاحية مالك المتجر» |
| **ميزة الباقة** | «المواقع والفروع» `multi_location` — متوقفة افتراضياً لكل المتاجر. إن لم تكن مفعّلة يختفي قسم «المواقع» من الإعدادات وتظهر شاشة «المواقع» بـ «هذه الميزة غير متاحة في خطتك» |
| **لمالك المتجر فقط؟** | نعم |
| **مكانها** | «الإعدادات» ← «المواقع» (`/dashboard/settings/locations`)، أو شاشة «المواقع» قبل التفعيل (`/dashboard/locations`) |

## ماذا يتغيّر؟

| | تعدد المواقع متوقف | تعدد المواقع مفعّل |
|---|---|---|
| مصدر الكمية | رقم واحد لكل منتج (أو متغير) | كمية لكل موقع؛ الرقم العام للمنتج يُحدَّث تلقائياً من مواقعه |
| تعديل الكمية | دون موقع | يجب اختيار الموقع ([تعديل الكمية](adjust-stock.md)) |
| جدول المخزون | عمود «الكمية» | فلتر «الموقع» وأعمدة «الفعلي» و«المحجوز» و«الحجر» و«المتاح» |
| أوامر الشراء | تُستلم في أول موقع نشط | تختار «موقع الاستلام» ([أوامر الشراء](purchase-orders.md)) |
| طلب الإعدام | دون موقع | يجب اختيار الموقع |

## الخطوات

### التشغيل

1. افتح «المواقع». إن كان التعدد متوقفاً تظهر «ماذا يتغير عند التفعيل؟».
2. اضغط «تفعيل المواقع المتعددة» ثم «تفعيل» في «تفعيل المواقع المتعددة؟». يظهر «فُعِّلت المواقع المتعددة».
3. أو من «الإعدادات» ← «المواقع»: شغّل «تعدد المواقع»، ثم احفظ وأكّد «تفعيل تعدد المواقع».

![شاشة «المواقع» قبل التفعيل](../../_assets/merchant/10-inventory-locations-procurement/multi-location-mode-1.png) <!-- capture: /dashboard/locations on a store with the mode off, desktop 1440, mock mode -->

### الإيقاف

1. افتح «الإعدادات» ← «المواقع» («يغيّر بنية المخزون — يُحفظ بعد تأكيد.»).
2. أطفئ «تعدد المواقع» واحفظ، ثم أكّد «إيقاف تعدد المواقع»: «ستُدمج كميات كل المواقع في مخزون واحد؛ لا يمكن فصلها تلقائياً بعد ذلك.»
3. إن كان المخزون في موقع واحد أو لا مخزون: يُوقف فوراً، ويظهر «أُوقف تعدد المواقع».
4. إن كان المخزون في **أكثر من موقع**: يظهر «لم يُوقف تعدد المواقع» مع السبب: «يوجد مخزون في أكثر من موقع؛ الإيقاف يجعل مخزون كل منتج رقماً واحداً (مجموع المواقع).» وقائمة المواقع، ولكل موقع «(العدد) منتجاً بمخزون».
5. اختر:
   - «دمج الكميات وإيقاف»: يُوقف التعدد. يظهر «أُوقف تعدد المواقع ودُمجت الكميات».
   - «مراجعة المواقع أولاً»: يعود بك إلى «المواقع» دون تغيير.

![تعارض الإيقاف مع المخزون الموزّع](../../_assets/merchant/10-inventory-locations-procurement/multi-location-mode-2.png) <!-- capture: /dashboard/settings/locations → switch off → save → confirm, desktop 1440, mock mode -->

## ما يحدث بعد ذلك

- **الدمج لا ينقل شيئاً**: الرقم العام لكل منتج هو أصلاً مجموع مواقعه، فيبقى كما هو ويصبح المصدر الوحيد. كميات المواقع لا تُستخدم بعد الإيقاف.
- **بعد التشغيل** لا تُنشأ كميات للمواقع تلقائياً. المنتجات تحتفظ بأرقامها العامة، وأول كمية لمنتج في موقع تأتي من [استلام أمر شراء](purchase-orders.md) إلى ذلك الموقع.
- المواقع نفسها لا تُحذف عند الإيقاف.

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «يوجد مخزون في أكثر من موقع؛ الإيقاف يجعل مخزون كل منتج رقماً واحداً (مجموع المواقع).» | الإيقاف ومخزون في موقعين أو أكثر | «دمج الكميات وإيقاف» أو «مراجعة المواقع أولاً». |
| «قسم «المواقع» غير مفعّل في خطة متجرك» | ميزة «المواقع والفروع» خارج باقتك | [ما المتاح في باقتي](../02-dashboard-shell/plan-features.md). |
| «تحتاج صلاحية مالك المتجر» | فتحت القسم بحساب موظف | الإعداد لمالك المتجر. |
| «تعذّر الحفظ.» · «تعذّر التفعيل» | خطأ أثناء الحفظ | أعد المحاولة. |

## حدود يجب معرفتها

- الإيقاف مع مخزون في موقع واحد فقط لا يسأل عن الدمج.
- التشغيل لا يُرفض أبداً.

## قيود معروفة

> **قيد معروف:** نافذة التأكيد عند التشغيل تقول إن «المخزون الحالي يُنقل إلى الموقع الافتراضي»، لكن التشغيل لا ينقل شيئاً: لا تظهر كميات في أي موقع حتى تستلم إليه أمر شراء.

> **قيد معروف:** شاشة «المواقع» قبل التفعيل تعرض «الموقع الحالي» باسم ثابت («المستودع الرئيسي»، `WH-01`)، أياً كان اسم موقعك.
