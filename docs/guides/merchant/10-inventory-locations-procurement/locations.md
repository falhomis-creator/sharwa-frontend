# إضافة المواقع وتنظيمها: المستودعات والفروع ونقاط الاستلام والمركبات

> **المصدر**: DOC-364 · INT-025 (M22) · الجرد: المجال 10 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 33)

الموقع مكان يُخزَّن فيه المخزون أو يُباع منه أو يُسلَّم منه: مستودع، فرع، خزانة استلام، مركبة، مستودع مشترك، أو مورد يشحن عنك. «المستودعات والفروع ونقاط الاستلام والمركبات — كل موقع بما يستطيع فعله، لا بنوع جامد.» المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | مالك المتجر يضيف المواقع ويعدّلها؛ أي عضو في الفريق يقرؤها |
| **الصلاحية المطلوبة** | لا يوجد مفتاح صلاحية للمواقع؛ الإضافة والتعديل لمالك المتجر وحده: «إدارة المواقع مقصورة على مالك المتجر.» |
| **ميزة الباقة** | «المواقع والفروع» `multi_location` — متوقفة افتراضياً. إن لم تكن مفعّلة تظهر: «هذه الميزة غير متاحة في خطتك» |
| **لمالك المتجر فقط؟** | الإضافة والتعديل نعم |
| **مكانها** | القائمة الجانبية ← «المنتجات» ← «المواقع» (`/dashboard/locations`). موقع جديد: `/dashboard/locations/new` |

## قبل أن تبدأ

- ميزة الباقة تفتح الشاشة. ثم يجب **تفعيل تعدد المواقع** في متجرك؛ قبل ذلك تظهر «تعدد المواقع غير مفعّل. متجرك يعمل من موقع واحد.» وزر «تفعيل المواقع المتعددة» ([تشغيل تعدد المواقع وإيقافه](multi-location-mode.md)).
- الموقع **لا يُختار له «نوع» مسبق**: تفعّل ما يستطيع فعله (القدرات) وتختار ملكيته، ويحسب المتجر «نوع العرض» منها.

## الخطوات

### إضافة موقع

1. افتح «المواقع» واضغط «موقع جديد».
2. **الهوية**: «الاسم» و«الكود» (مثل WH-01 أو BR-JED-02)، و«الموقع الأب» إن وُجد، و«نشط».
3. **العنوان**: «العنوان النصي»، «المدينة»، «الهاتف»، «خط العرض» و«خط الطول». الصق «lat,lng» في أي حقل لتعبئة الاثنين.
4. **القدرات**: فعّل ما ينطبق (الجدول التالي).
5. **الملكية**: «مملوك» أو «امتياز» أو «مستودع طرف ثالث» أو «مورد دروبشيبينج».
6. أكمل الأقسام التي تظهر حسب اختياراتك (ساعات العمل، الخزانة، الامتياز، المورد، المركبة).
7. عند الحاجة أضف «المراجع الخارجية».
8. اضغط «إنشاء الموقع» (أو ⌘S). يظهر «أُنشئ الموقع» ومعه «نوع العرض: (النوع)».

![نموذج «موقع جديد»](../../_assets/merchant/10-inventory-locations-procurement/locations-1.png) <!-- capture: /dashboard/locations/new, desktop 1440, mock mode, fullPage -->

### تعديل موقع أو تعطيله

1. اضغط الموقع في القائمة. تفتح صفحته بتبويبات «البيانات» و«المخزون» و«الموظفون».
2. في «البيانات» عدّل ما تريد واضغط «حفظ». يظهر «حُفظ الموقع».
3. للتعطيل أطفئ «نشط» واحفظ. يظهر «تعطيل الموقع؟» وفيه أثر التعطيل: «يحمل هذا الموقع (الكمية) وحدة مخزون و(العدد) طلبات مفتوحة. بعد التعطيل لن تُوجَّه إليه طلبات جديدة وسيبقى مخزونه حتى تنقله.»
4. اضغط «تعطيل»، أو «إبقاء الموقع نشطاً».

> **تنبيه:** التعطيل لا يُرفض حتى لو كان في الموقع مخزون أو طلبات مفتوحة. الطلبات المفتوحة هي التي تُجهَّز أو تنتظر الاستلام فيه. أنهِها وانقل المخزون أولاً.

## القدرات

| القدرة | معناها |
|---|---|
| «يخزّن» | يحمل كميات مخزون ويظهر في جدول المخزون |
| «يشحن للعميل» | يمكن أن يكون مصدر طلبات التوصيل |
| «عبور» | تمرّ البضاعة منه ولا تُخزَّن طويلاً |
| «متنقّل» | مركبة أو كشك متحرك |
| «افتراضي» | بلا عنوان فعلي (مورد خارجي مثلاً) — **لا إحداثيات**: تُحذف تلقائياً |
| «يخدم زوّاراً» | عملاء يأتون إليه بأنفسهم |
| «نقطة بيع» | فيه جهاز POS للبيع المباشر |
| «نقطة استلام» | العميل يستلم طلبه منه |

## الأقسام الإضافية حسب الموقع

| القسم | يظهر حين | حقوله |
|---|---|---|
| «ساعات العمل» | «نقطة استلام» أو «يخدم زوّاراً» | لكل يوم: من وإلى، أو «مغلق». الأيام بترتيب بداية أسبوعك |
| «تفاصيل الخزانة» | «نقطة استلام» | «المزوّد»، «رمز الخزانة»، «السعة» (عدد الخانات) |
| «الامتياز» | الملكية «امتياز» | «صاحب الامتياز»، «نهاية العقد» |
| «مورد الدروبشيبينج» | الملكية «مورد دروبشيبينج» | «قناة التواصل» («واتساب» أو «بريد إلكتروني» أو «API / Webhook») و«جهة الاتصال»: رقم واتساب أو بريد أو رابط Webhook |
| «المركبة» | «متنقّل» | «رقم اللوحة»، «هاتف السائق» |

إن أطفأت القدرة التي يتبعها قسم، يُحذف القسم عند الحفظ.

| الشرط | «نوع العرض» |
|---|---|
| الملكية «مورد دروبشيبينج» | «مورد دروبشيبينج» |
| «متنقّل» | «مركبة متنقلة» |
| الملكية «مستودع طرف ثالث» | «مستودع مشترك (3PL)» |

| «يخزّن» و«يشحن للعميل» و«يخدم زوّاراً» و«نقطة بيع» | «موقع هجين» |
| «يخزّن» و«يشحن للعميل» دون «يخدم زوّاراً» | «مستودع مغلق» |
| «يخدم زوّاراً» و«نقطة بيع» | «فرع تجزئة» |
| «نقطة استلام» | «نقطة استلام» |
| غير ذلك | «موقع» |

## الموقع الأب

يمكن أن يتبع الموقع موقعاً آخر، مثل خزانة استلام تابعة لفرع. في القائمة يظهر كل موقع أب ثم المواقع التابعة له مباشرة. **لا يتبع موقع أحد المواقع التابعة له** (لا حلقات).

## القائمة

![قائمة «المواقع»](../../_assets/merchant/10-inventory-locations-procurement/locations-2.png) <!-- capture: /dashboard/locations, desktop 1440, mock mode -->

- **الأعمدة**: «الكود»، «الاسم»، «المدينة»، «نوع العرض»، «الملكية»، «الحالة» («نشط» أو «معطّل»)، «منتجات مخزّنة» (عدد المنتجات التي لها كمية أكبر من صفر فيه).
- **البحث** «الاسم أو الكود أو المدينة» (لا يفرّق بين أشكال الهمزة والتاء المربوطة)، وفلاتر «القدرة» و«الملكية» و«الحالة».
- زر «قواعد التوجيه» ينقلك إلى [قواعد التوجيه](routing-rules.md).

## الحقول

| الحقل | إلزامي؟ | القيود |
|---|---|---|
| «الاسم» | نعم | حتى 150 حرفاً |
| «الكود» | نعم | 2 إلى 20: أحرف لاتينية وأرقام وشرطات، يبدأ بحرف أو رقم. يُحفظ بأحرف كبيرة ولا يتكرر |
| «العنوان النصي» · «المدينة» · «الهاتف» | لا | 2000 / 100 / 20 حرفاً |
| «خط العرض» · «خط الطول» | لا | بين −90 و90 / بين −180 و180 |
| «نهاية العقد» | لا | تاريخ |
| «جهة الاتصال» (Webhook) | — | تبدأ بـ `http://` أو `https://` |
| «جهة الاتصال» (واتساب) | — | 20 خانة على الأكثر |
| «السعة» | لا | رقم موجب |
| «المراجع الخارجية» | لا | «النظام» و«المرجع» لكل سطر، مثل معرّف الموقع في نظام مستودع أو شركة شحن |

## الرسائل التي قد تظهر لك

| الرسالة | السبب | ماذا تفعل |
|---|---|---|
| «اسم الموقع مطلوب.» | الاسم فارغ | اكتبه. |
| «الكود أحرف لاتينية وأرقام وشرطات (2–20).» | كود غير صحيح | صحّحه. |
| «هذا الكود مستخدم لموقع آخر.» | الكود موجود | اختر كوداً آخر. |
| «الموقع الأب غير صالح.» | الأب غير موجود، أو يتبع هذا الموقع | اختر أباً آخر. |
| «خط العرض بين -90 و90.» · «خط الطول بين -180 و180.» | إحداثيات خارج الحد | صحّحها. |
| «أدخل الساعات بصيغة HH:MM أو علّم اليوم مغلقاً.» | ساعات ناقصة | أكمل الساعات أو اختر «مغلق». |
| «تاريخ نهاية العقد غير صالح.» | تاريخ غير صحيح | صحّحه. |
| «رابط الـ Webhook يبدأ بـ http:// أو https://» | رابط غير صحيح | صحّحه. |
| «رقم واتساب 20 خانة على الأكثر.» | الرقم طويل | صحّحه. |
| «السعة رقم موجب.» | سعة سالبة | صحّحها. |
| «إدارة المواقع مقصورة على مالك المتجر.» | موظف يحاول الإضافة أو التعديل | اطلب ذلك من المالك. |
| «الموقع غير موجود.» | الموقع حُذف أو الرابط خطأ | ارجع إلى القائمة. |

## حدود يجب معرفتها

- القائمة غير مقسّمة إلى صفحات.
- التعطيل لا يحذف الموقع ولا ينقل مخزونه.
- قسم المورد هنا لمورد **الدروبشيبينج** الذي يشحن عنك. مورد **الشراء** الذي تشتري منه البضاعة في [الموردين](suppliers.md).
