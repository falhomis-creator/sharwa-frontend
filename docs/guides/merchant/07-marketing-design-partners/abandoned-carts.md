# متابعة السلات المتروكة وإرسال التذكيرات

> **المصدر**: DOC-346 · INT-019 (M13) · INT-013 · الجرد: المجال 7 · آخر مراجعة على الكود: 2026-10-28 (الخطوة 32)

السلة المتروكة سلة أضاف فيها المشتري منتجات ولم يُكمل الطلب. يرصدها المتجر، ويذكّر صاحبها عبر واتساب مرتين، ويرسل في التذكير الثاني كوبون استرداد. المصطلحات في [مسرد الأدلة](../../_glossary.md).

## لمن هذه الصفحة؟

| | |
|---|---|
| **الجمهور** | مالك المتجر فقط |
| **الصلاحية المطلوبة** | لا يوجد مفتاح صلاحية؛ يرى الموظف: «السلات المتروكة مقصورة على مالك المتجر.» |
| **ميزة الباقة** | «السلات المتروكة» `abandoned_carts` — إن لم تكن مفعّلة تظهر: «هذه الميزة غير متاحة في خطتك» |
| **لمالك المتجر فقط؟** | نعم |
| **مكانها** | القائمة الجانبية ← «التسويق» ← «السلات المتروكة والاسترداد الآلي» (`/dashboard/marketing/abandoned-carts`). الإعدادات: «إعدادات التذكير» (`/dashboard/marketing/abandoned-carts/settings`) |

## متى تُعدّ السلة متروكة؟

| الحالة | معناها |
|---|---|
| «نشطة» | المشتري تفاعل مع سلته خلال الساعتين الأخيرتين |
| «متروكة» | مرّت ساعتان على آخر نشاط دون طلب |
| «مستردَّة» | أكمل المشتري الطلب بعد أن تُركت السلة. يظهر «استُردّت بالطلب» برقم الطلب |

تُحدَّث الحالات كلما فتحت القائمة: «سلات لم تُكمَل خلال ساعتين. التذكير عبر واتساب، والثاني يحمل كوبون استرداد.»

## القائمة

![قائمة «السلات المتروكة»](../../_assets/merchant/07-marketing-design-partners/abandoned-carts-1.png) <!-- capture: /dashboard/marketing/abandoned-carts, desktop 1440, mock mode -->

- **العدادات** أعلى القائمة: «الكل»، «نشطة»، «متروكة»، «مستردَّة»، لكل منها عدد سلاتها كلها. اضغط واحدة لتصفية القائمة.
- **الأعمدة**: «العميل» (الاسم والهاتف، أو «زائر»)، «العناصر»، «القيمة»، «الحالة»، «التذكيرات» («لم يُرسل» أو 1/2 أو 2/2 ووقت آخرها)، «آخر نشاط».
- **البحث** «ابحث بالاسم أو الهاتف» (3 أرقام على الأقل من الهاتف)، و«من» و«إلى» لتاريخ آخر نشاط، وفلتر «الحالة».

### تفاصيل السلة

اضغط سلة لفتح تفاصيلها: «الحالة»، «القيمة»، «التذكيرات»، «كوبون الاسترداد» إن أُرسل، و«العناصر» بكمياتها.

> **ملاحظة:** أسعار العناصر في التفاصيل هي **أسعار المنتجات الآن** بعملة السلة، لا أسعارها يوم أضافها المشتري. المنتج الذي حُذف يظهر «منتج محذوف».

![تفاصيل سلة متروكة وزر «إرسال تذكير»](../../_assets/merchant/07-marketing-design-partners/abandoned-carts-2.png) <!-- capture: /dashboard/marketing/abandoned-carts?status=abandoned → first row, desktop 1440, mock mode -->

## الخطوات

### إرسال تذكير يدوي

1. افتح سلة حالتها «متروكة».
2. اضغط «إرسال تذكير». يسألك: «إرسال تذكير عبر واتساب؟» ومعه وقت آخر تذكير.
3. اضغط «إرسال». يظهر «أُرسل التذكير».

التذكير اليدوي هو **التذكير التالي** للسلة: إن لم يُرسل شيء يُرسل الأول، وإن أُرسل الأول يُرسل الثاني بكوبونه. له نفس النص والقناة والكوبون اللذين يستخدمهما الإرسال التلقائي. لا يوجد تذكير ثالث.

### ضبط التذكيرات التلقائية

1. من القائمة افتح «إعدادات التذكير». تفتح «إعدادات تذكير السلات».
2. فعّل «تفعيل تذكيرات السلات المتروكة».
3. اختر القنوات و«الحد الأدنى لقيمة السلة (ر.س)».
4. اضبط «التذكير الأول» و«التذكير الثاني — مع كوبون» (الجدول التالي).
5. اضبط «نسبة خصم الكوبون %» و«صلاحية الكوبون (ساعات)».
6. احفظ. يظهر «حُفظت الإعدادات».

![«إعدادات تذكير السلات»](../../_assets/merchant/07-marketing-design-partners/abandoned-carts-3.png) <!-- capture: /dashboard/marketing/abandoned-carts/settings, desktop 1440, mock mode -->

| «واتساب» | — | تشغيل أو إيقاف | «عبر رقم المتجر المربوط.» |

| «التذكير في المحادثة أيضاً» | — | تشغيل أو إيقاف | «إن كانت السلة بدأت من محادثة (واتساب/تيليجرام) يُرسل التذكير في نفس المحادثة.» |
| «الحد الأدنى لقيمة السلة (ر.س)» | نعم | 0 أو أكثر | «السلات الأقل لا تُذكَّر. 0 = الكل.» |

| «نص الرسالة» — التذكير الأول | نعم | المتغيرات `{customer_name}` و`{cart_url}` فقط | |
| «بعد (ساعات)» — التذكير الثاني | نعم | عدد صحيح، 1 أو أكثر | من وقت **التذكير الأول** (انظر قسم القيود المعروفة) |
| «نص الرسالة» — التذكير الثاني | نعم | `{customer_name}` و`{cart_url}` و`{discount_percent}` و`{discount_code}` | |
| «نسبة خصم الكوبون %» | نعم | عدد صحيح من 0 إلى 100 | «0 = بلا كوبون.» |
| «صلاحية الكوبون (ساعات)» | نعم | عدد صحيح، 1 أو أكثر | |

### متغيرات الرسالة

| المتغير | يُستبدل بـ |
|---|---|
| `{customer_name}` | اسم العميل، أو «عميلنا العزيز» إن لم يُعرف |
| `{cart_url}` | رابط يعيد المشتري إلى سلته كما تركها |
| `{discount_percent}` | نسبة خصم الكوبون |
| `{discount_code}` | كود كوبون الاسترداد |

> **ملاحظة:** إن حذفت `{cart_url}` من النص بالخطأ يُضاف رابط السلة تلقائياً في آخر الرسالة.

## ما يحدث بعد ذلك

- **التذكير الأول** يُرسل تلقائياً بعد «بعد (ساعات)» من آخر نشاط في السلة، للسلات «متروكة» التي فيها رقم هاتف وقيمتها تبلغ الحد الأدنى.
- **التذكير الثاني** يُرسل بعد مدته من وقت التذكير الأول، ومعه كوبون استرداد إن كانت النسبة أكبر من 0.
- **كوبون الاسترداد** يُنشأ مرة واحدة لكل سلة: كوده يبدأ بـ `BACK`، يصلح لكل المنتجات، **مرة واحدة فقط**، وينتهي بعد «صلاحية الكوبون (ساعات)». يظهر في قائمة [الكوبونات](coupons.md).
- **القناة**: إن كان «التذكير في المحادثة أيضاً» مفعّلاً وللعميل محادثة سابقة يُرسل فيها؛ وإلا عبر واتساب إن كان مفعّلاً.
- حين يفتح المشتري الرابط تعود سلته كما تركها ([ما يراه المشتري](../../buyer/05-storefront/cart-reminders.md)). إن أكمل الطلب تصبح السلة «مستردَّة».

## حدود يجب معرفتها

- السلة تصبح «متروكة» بعد ساعتين من آخر نشاط.
- تذكيران فقط لكل سلة، يدوياً أو تلقائياً.
- كوبون الاسترداد يُستخدم مرة واحدة.
- التذكير اليدوي يُرسل حتى لو كانت التذكيرات التلقائية موقوفة أو كانت قيمة السلة أقل من الحد الأدنى.

## قيود معروفة

> **قيد معروف:** بعد إرسال التذكيرين يبقى زر «إرسال تذكير» ظاهراً مع عبارة «أُرسل التذكيران. يمكن إرسال تذكير إضافي يدوياً.»، لكن الإرسال يُرفض: لا يوجد تذكير ثالث.

> **قيد معروف:** إرشاد «بعد (ساعات)» في التذكير الثاني يقول «من وقت ترك السلة.»، لكن المدة تُحسب من وقت إرسال التذكير الأول.
