# مسرد أدلة المستخدم

> **المصدر**: DOC-284 · INT-001…INT-049 · الجرد A.4، A.5، A.6 · آخر مراجعة على الكود: 2026-10-27 (الخطوة 10)
> **الحالة**: معتمد — راجعه fares واعتمده في 2026-10-30 (DOC-284، الخطوة 52).

المصطلح الذي يظهر في الواجهة هو المصطلح الذي يُكتب في الأدلة، مصطلحاً واحداً لكل مفهوم. هذا المسرد مخصص لكتّاب الأدلة العربية، وكل دليل يربط به. المسرد الشامل للمطوّرين (عربي ↔ إنجليزي، الوحدات M01–M49) هو [`docs/glossary.md`](../glossary.md).

**كيف تقرأ عمود «في الواجهة»**: ✓ تعني أن النص وُجد حرفياً في شاشات المنصة عند مراجعة الكود. إن لم تستخدم الواجهة الكلمة التي يقترحها المسرد، فالعمود يذكر ما تستخدمه الواجهة فعلاً، وهو ما يُكتب في الدليل.

## 1. الأشخاص والأدوار

| المصطلح | في الواجهة | معناه | لا تخلط مع |
|---|---|---|---|

| الشريحة | «الشريحة» ✓ | مجموعة عملاء بقاعدة ثابتة: «الكل»، «سلات متروكة»، «خامل» (90 يوماً بلا طلب غير ملغى)، «اشترى منتجاً». عددها هو عدد من تصله الحملة. | — |
| ثقة الدفع عند الاستلام | «ثقة الدفع عند الاستلام» · «عبر المنصة» · «في متجرك» ✓ | قراءتان منفصلتان لا تُدمجان: ثقة الرقم عبر كل متاجر شروة (للعلم)، وسجل رفض الاستلام في متجرك (ومنه قرار الإيقاف). | — |
| مالك المنصة | «مالك المنصة» ✓ | صاحب الصلاحية الكاملة في لوحة المنصة. | مالك المتجر |
| مشرف تشغيلي | «مشرف تشغيلي» ✓ | مستخدم لوحة المنصة يقرأ كل شيء ويعدّل المستحقات وشروة باي فقط. | مالك المنصة |

## 2. الباقة والميزة والصلاحية

| المصطلح | في الواجهة | معناه | لا تخلط مع |
|---|---|---|---|
| الباقة (الخطة) | «الباقة» ✓ · وفي رسائل المنع «خطتك» و«باقتك» ✓ | الاشتراك الذي تحدده المنصة للمتجر. الواجهة تستخدم الكلمتين؛ في شرحك اكتب «الباقة»، وانقل الرسائل كما هي. | الميزة |
| ميزة الباقة | «الميزة» ✓ | قسم من المنصة تفتحه المنصة أو تغلقه للمتجر كله (مثل «الحجوزات»). حين تكون متوقفة يختفي القسم من القائمة لكل من في المتجر، مالكاً وموظفين. | الصلاحية |
| الصلاحية | «الصلاحية» ✓ | إذن يملكه موظف بعينه (مثل «عرض الطلبات»). المالك يملك كل الصلاحيات. | ميزة الباقة |
| الاستثناء | «الاستثناءات» · «منح» · «حجب» ✓ | منح صلاحية لموظف أو حجبها عنه فوق ما يعطيه دوره. | الدور |
| الصلاحية النهائية | «الصلاحية النهائية» ✓ | ما يملكه الموظف فعلاً بعد الأدوار والاستثناءات. | — |
| لمالك المتجر فقط | «… مقصور على مالك المتجر.» · «… لمالك المتجر فقط.» ✓ | شاشة أو إجراء لا يفتحه أي موظف مهما كانت صلاحياته. | الصلاحية |
| طلب موافقة | «طلبات الموافقة المعلّقة» ✓ | طلب ينتظر قرار صاحب دور معيّن (إتلاف مخزون، أمر شراء، مسودة جملة، عجز وردية، خصم فوق الحد). | — |
| التعيين | «التعيينات» · «دور الصلاحيات» ✓ | دور يُسند للموظف في موقع بعينه؛ تُجمع صلاحيات كل تعييناته. الموظف بلا تعيين لا يدخل أي موقع. | الدور التشغيلي |
| الدور النظامي والمخصص | «الأدوار النظامية» · «الأدوار المخصصة» · «نسخ كدور مخصص» ✓ | النظامية الأربعة للقراءة فقط؛ المخصصة يُنشئها المتجر وتُعدَّل وتُحذف. | — |
| كلمة المرور المؤقتة | «كلمة مرور مؤقتة جديدة» · «كلمة مرور (الاسم) المؤقتة» ✓ | كلمة يصدرها المتجر للموظف وتظهر لمن أصدرها مرة واحدة فقط. | رمز التحقق |
| إنهاء الخدمة | «إنهاء الخدمة» · «مُنهى» ✓ | إيقاف دائم للموظف: لا يدخل، وتنتهي جلساته ورموزه، ويبقى سجله. | «معطّل» (إيقاف يمكن التراجع عنه) |
| الرمز الشخصي | «الرموز الشخصية» · «إنشاء رمز» ✓ | رمز `shw_pat_…` لموظف، صالح 90 يوماً، يظهر مرة واحدة. | كلمة المرور |
| جدول العمل | «الجدول» · «الالتزام بجدول العمل» ✓ | أوقات أسبوعية يُسمح فيها للموظف بالدخول، إن شُغِّل الالتزام به. | الوردية |
| سجل التدقيق | «سجل التدقيق» ✓ | سجل لا يُعدَّل لكل تغيير حساس، كل سطر مرتبط ببصمة السطر الذي قبله. | سجل الحركات |
| التنبيه السلوكي | «التنبيهات السلوكية» · «تنبيهات السلوك» ✓ | تنبيه حين يتجاوز موظف حداً يومياً للتصدير أو تصفّح بيانات العملاء أو الرسائل. | الإشعارات |

## 3. المال والمحافظ — ثلاث محافظ مختلفة

لا تكتب «المحفظة» وحدها أبداً.

| المصطلح | في الواجهة | لمن | معناه |
|---|---|---|---|
| محفظة المتجر | «محفظة المتجر» ✓ | مالك المتجر | رصيد المتجر لدى المنصة من مبيعاته. منها تُطلب السحوبات («طلبات السحب») وتظهر «المستحقات للمنصة». (المسرد العام اقترح «محفظة التاجر»؛ الواجهة تقول «محفظة المتجر».) |
| محفظة العميل | «محافظ العملاء» · «محفظة العميل» ✓ | مشترٍ في متجر واحد | رصيد المشتري داخل متجر واحد، بالريال السعودي دائماً. تُستخدم في الاسترجاع والدفع عند الشراء. |
| محفظة شروة باي | «محفظة شروة باي» ✓ | أي صاحب رقم هاتف، عبر كل المتاجر | محفظة على مستوى المنصة بأربعة أرصدة (عملة لكل رصيد). يدفع منها المتجر أيضاً مستحقات المنصة وبوالص شروة شيب. |
| نقاط الولاء | «نقاط الولاء» ✓ | مشترٍ في متجر واحد | نقاط يكسبها المشتري ويستبدلها برصيد في محفظة العميل. اكتب «نقاط الولاء» لا «النقاط» وحدها. |
| عملة العرض | «عملة العرض» ✓ | المتجر | العملة الأساسية للمتجر: يرى بها المشترون الأسعار أولاً، وتُحسب بها مبالغ اللوحة. |
| سعر الصرف | «أسعار الصرف» ✓ | المتجر | ثلاثة أسعار يحددها المالك: الدولار مقابل الريال السعودي، والريال السعودي مقابل اليمني (صنعاء) واليمني (عدن). |
| المستحقات للمنصة | «المستحقات للمنصة» ✓ | مالك المتجر | عمولات ورسوم تطبيقات تحصّلها المنصة من محفظة شروة باي للمتجر، لا من محفظة المتجر. |
| حساب الاستلام | «حسابات الاستلام» ✓ | مالك المتجر | حساب بنكي أو محفظة محلية للمتجر: يراه المشتري في التحويل اليدوي، ويُسحب إليه رصيد محفظة المتجر. |
| طلب السحب | «طلب سحب» · «طلبات السحب» ✓ | مالك المتجر | طلب نقل رصيد من محفظة المتجر إلى حساب استلام. يُخصم فوراً («محجوز») وتقرر فيه إدارة شروة. |
| بوابة الدفع | «ربط بوابات الدفع» ✓ | مالك المتجر | ربط مباشر ببنك أو محفظة («محفظة جيب»، «حاسب الكريمي») يدفع منه المشتري؛ المال يصل حسابك لدى البنك. |
| التحويل اليدوي | «قبول التحويل اليدوي» · «الدفع اليدوي» ✓ | مالك المتجر | المشتري يحوّل إلى أحد حسابات الاستلام ويرفع الإيصال. مفتاحه يتحكم أيضاً في ظهور الدفع عند الاستلام. |
| المصروفات التشغيلية | «المصروفات التشغيلية» ✓ | مالك المتجر وفريقه | قيود يدوية لتكاليف التشغيل (تغليف، إيجار، رواتب، أخرى). لا تُعدَّل ولا تُحذف، ولا تمسّ أي محفظة. |

العملات الأربع كما تكتبها الواجهة: «ريال سعودي»، «دولار أمريكي»، «ريال يمني (صنعاء)»، «ريال يمني (عدن)». التفاصيل في [كيف تُعرض المبالغ](merchant/08-finance/money-display.md).
