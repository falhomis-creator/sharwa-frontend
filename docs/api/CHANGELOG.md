### Known open items at baseline (inventory A.13)

The IP allow-list addresses for `enforce_ip_whitelist` are not built (no model; INT-022). The Meta catalog sync needs a Meta category mapping that no screen offers, and TikTok categories are a static starter list (INT-037). `bundle_selection` in cart actions is not wired, and the merchant order detail does not show a line's personalization (INT-045). Haggling drafts (`NegotiationDraft`) are not wired (INT-044). Verifying the pickup code at the counter is not built (INT-015). `CentralCustomerTrust` is a merchant signal only (INT-014/INT-017). The smsa carrier `test_connection` is not wired (INT-021).
